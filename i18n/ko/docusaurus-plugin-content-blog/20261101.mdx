안녕하세요, 개발자 강혁진(Coupy)입니다.  
얼리 액세스가 시작된 이후로는 처음 인사드립니다.

[저번 글](https://mirai.urlate.coupy.dev/ko/blog/urlate-early-access)로부터 벌써 1년하고도 반이라는 시간이 흘렀습니다.  
작년 6월 [해군에 입대](https://x.com/coupyworks/status/1939419418825760808)한 이후로 어떻게든 게임 개발을 이어나가고자 많은 노력을 기울였는데 생각보다 쉽진 않았습니다.

무엇보다 큰 난관은 **패턴 개발**이었습니다.  
얼리 액세스 시작 이후로 [단](https://youtu.be/FKY9OoLCv48) [3](https://youtu.be/F7wHIcvfHF0)[개](https://youtu.be/mDUqfkVUf_Y)의 패턴이 만들어졌습니다.  
[2024년의 게시글](https://mirai.urlate.coupy.dev/ko/blog/urlate-dev-progress#패턴-제작-진행-현황)에서 패턴 제작의 어려움에 대해 얘기하긴 했었지만 이젠 정말 뭔가 대안을 찾아봐야 할 것 같습니다.  
이대로면 평생 패턴만 만들어야 될지도..

하지만 난관만 있었던 건 아닙니다.  
[AI](https://claude.ai/)의 발전으로, 부족한 시간에도 게임을 개선하는 데에 큰 도움을 받을 수 있었습니다.  
얼리 액세스가 시작되면서 [v1.0.0-rc.1](https://github.com/HyeokjinKang/URLATE/releases/tag/v1.0.0-rc.1) 버전이 배포됐었는데 이후 [789건의 커밋](https://github.com/HyeokjinKang/URLATE/compare/v1.0.0-rc.1...main)이 이뤄졌습니다.  
프로젝트 전체의 커밋 총량이 [1,451건](https://github.com/HyeokjinKang/URLATE/commits/main/)인 점을 생각해보면 엄청난 양이 아닐 수 없습니다.

서론이 길었습니다.  
글을 작성 중인 시점을 기준으로 [v1.0.0-rc.6](https://github.com/HyeokjinKang/URLATE/releases/tag/v1.0.0-rc.6) 버전이 서비스 중입니다.  
얼리 액세스의 시작 시점으로부터 현재까지 어떤 변경사항들이 있었고, 앞으로 **정식 출시**를 위해 어떤 준비가 남았는지 정리해보겠습니다.

## 랜딩 페이지

![새로운 랜딩 페이지](/img/20261101/index.webp)

- **랜딩 페이지가 완전히 새로워졌습니다!**
  - 최근 공지와 블로그 글을 바로 볼 수 있습니다.
  - 게임에 대한 간략한 소개가 추가되었습니다.
  - 페이지 좌측 상단에 현재 접속 중인 게임의 버전이 표시됩니다.
- [FedCM API](https://developer.mozilla.org/en-US/docs/Web/API/FedCM_API)를 지원하여 **원클릭 로그인**이 가능해졌습니다.
- 정보, 개인정보 처리방침, 오류 페이지 등의 화면도 함께 바뀌었습니다.

## 게임 플레이

![다듬어진 게임 플레이](/img/20261101/play.webp)

### 판정과 점수
- 판정 구간을 **프레임 단위**로 다시 정하고, 정확도와 점수의 통합 배율을 다시 계산했습니다.
- 홀드 노트에 **`떼기 판정`** 과 **`틱`** 개념이 추가되었습니다.
- 휠 노트에 **타이밍 판정**이 다시 추가되었습니다.
- 자세한 내용은 [**판정 시스템 및 노트 처리 방식 리워크 안내**](https://mirai.urlate.coupy.dev/ko/announcements/20261029)를 참고해주세요.

### 연출과 소리
- **판정 이펙트 연출**이 리워크되었습니다.
  - `Perfect` 판정에 lens flare 효과가 표시됩니다.
  - 판정에 따라 FAST/LATE 텍스트가 표시됩니다.
  - 판정에 따른 dust 효과가 추가되었습니다.
  - 글자에 wave 효과가 추가되었습니다.
  - 물결 효과를 약간 손봤습니다.
- 선택 가능한 6종의 히트사운드를 제작했습니다.
  - 홀드 노트의 틱마다 히트사운드에 어울리는 틱 소리가 재생됩니다.
- 총알의 파괴 효과를 개선했습니다.

### 조작
- **AUTO PLAY** 기능이 추가되었습니다.
- 일시정지한 위치를 클릭해야 게임을 재개할 수 있도록 변경되었습니다.
- [Pointer Lock API](https://developer.mozilla.org/ko/docs/Web/API/Pointer_Lock_API)를 지원하여 게임을 플레이하는 동안 커서를 잠급니다.
- 직접 입력(Raw Input) 옵션이 추가되었습니다.
- [pointerrawupdate](https://developer.mozilla.org/en-US/docs/Web/API/Element/pointerrawupdate_event)를 이용한 입력을 지원하여 커서를 더 빠르게 추적합니다.
- 감도를 0.25x부터 3x까지 조정할 수 있게 되었습니다.
- 재생 속도를 0.5x부터 2x까지 0.1 단위로 조정할 수 있습니다.

### 싱크
- 수직 동기화(V-Sync) 옵션이 추가되었습니다.
  - 수직 동기화가 꺼진 경우 화면을 저지연 모드로 전환합니다.
- 화면 싱크 오프셋이 추가되었습니다.

### 선곡
- 정렬, 난이도 등의 모드 설정을 기억합니다.
  - 설정은 계정에 저장되어 다른 환경에서 접속해도 유지됩니다.

### 버그 수정
- AP/FC 이펙트 표출 시 프레임 드랍 현상이 생기던 문제 수정
- 콤보 텍스트가 성능 저하를 유발하던 문제 수정
- 폭발 이펙트가 여러 번 나오던 문제 수정
- 총알 파괴 이펙트가 엉뚱한 위치에 나타나던 문제 수정
- 선곡 화면에서 비주얼라이저가 의도와 달리 표시되던 문제 수정
- 곡을 빠르게 넘기면 여러 곡이 동시에 재생되던 문제 수정
- 총알의 각도와 실제 궤적이 다르던 문제 수정
- `retry`에 관한 문제 3종 수정

## 에디터

![리워크된 에디터 화면](/img/20261101/editor.webp)

### 테스트와 미리보기
- 테스트와 미리보기 모두에 **AUTO PLAY** 기능이 추가되었습니다.

### 타임라인
- 트리거와 홀드 노트에 **지속시간을 표시하는 막대**가 추가되었습니다.
- **스크롤바**가 추가되어 탐색이 편해졌습니다.
- **요소 종류별 필터**가 추가되었습니다.
- 노트와 트리거 종류를 구별할 수 있게 되었습니다.
- 겹침 방지 알고리즘을 개선했습니다.
- 기타 사소하지만 신경 쓰이는 문제들을 수정했습니다.

### 선택과 편집
- 좌우·상하·원점 대칭 기능이 추가되었습니다.
- 다중 요소 선택 기능이 추가되었습니다.
  - `Ctrl/Shift + 클릭`과 `드래그`로 선택/해제할 수 있습니다.
  - 선택 요소를 한꺼번에 드래그하거나, `Alt + 방향키`로 박자 단위로 이동하거나, 대칭시킬 수 있습니다.
  - 같은 타입의 요소를 선택한 경우 설정 패널에서 속성값을 일괄 수정할 수 있습니다.
- `Range Copy/Paste`를 삭제하고 `Copy/Paste`에 통합했습니다.
  - 다중 요소 선택 기능과 결합되어 익숙한 편집 경험을 제공합니다.
  - 클립보드가 저장되어 창을 새로고침하거나, 곡을 교체하거나, 다른 탭으로 옮겨도 같은 요소를 붙여넣을 수 있습니다.
- `File System Access API`를 통해 패턴을 저장할 때마다 파일을 새로 다운로드하지 않고 기존 파일을 덮어씁니다.
  - 글을 작성하는 시점 기준으로 `Chrome`, `Edge` 등 Chromium 기반 브라우저에서만 지원합니다.
- 저장하지 않은 변경사항이 있으면 `*` 기호로 알려주고, 페이지를 나갈 때 경고합니다.
- 박자에 맞춰 메트로놈이 재생됩니다.

### 패턴 버전 1.1
- 목표값까지 특정 시간 동안 **서서히 바뀌는 트리거**를 지원합니다.
  - Speed, BPM, Opacity에서 사용할 수 있습니다.

## 정식 출시까지

변경사항이 많았던 만큼, 게임의 기본기는 이제 어느 정도 갖춰졌다고 생각합니다.  
판정, 조작, 연출, 에디터까지 그동안 마음에 걸렸던 부분들을 대부분 손볼 수 있었습니다.

남은 가장 큰 숙제는 역시 **패턴**입니다.  
정식 출시 전까지 모든 곡에서 다양한 난이도를 즐기실 수 있도록, 패턴 제작 과정 자체를 다시 고민하고 있습니다.  
이번에 에디터를 크게 손본 것도 그 준비의 일부입니다.

앞으로 남은 작업은 대략적으로 아래와 같습니다.
- **패턴 제작**
- 선곡 화면 개선
  - 모드(재생 속도 등) 구성 개편
- 프로필 신고 기능 추가
- 보안 점검 및 개선

## 마무리

군 복무와 병행하다 보니 소식을 전하는 데에 1년이 넘게 걸렸습니다.  
그동안 기다려주신 분들께 죄송하면서도 감사한 마음입니다.

앞으로는 MIRAI 블로그를 기술 블로그처럼 운영해볼까 합니다.  
게임을 만들며 겪은 일화나 고민했던 선택, 기술적인 이야기들을 풀어볼 생각입니다.  
다양한 이야기로 더 자주 찾아뵐 수 있도록 하겠습니다.

모든 분들께 보답해드릴 수 있도록 멈추지 않고 더욱 발전하는 URLATE가 되겠습니다.  
항상 감사합니다.
